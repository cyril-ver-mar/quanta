# Playbook 07 — i18n

**Checklist ID:** C5  
**Ask user:** implement yes / no / later?

## Goal

UI strings not hard-coded forever; English first is fine.

## Pattern

- Central dict or gettext-like `t("key", **kwargs)`  
- Language in Settings / `session_state`  
- New features add keys in the same module  

## Don’t

Scatter user-visible English only inside deep services (prefer UI layer + thin message codes).
